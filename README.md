# Джарвис

Голосовой помощник для Android: расписание на день с напоминаниями, таймеры, заметки, погода, ИИ (по желанию), игры и приколы.

## Как собрать APK на GitHub

1. Загрузи все файлы проекта в репозиторий, включая папку `.github/workflows/android.yml` (если она не загрузилась перетаскиванием, создай файл вручную: Add file → Create new file, имя `.github/workflows/android.yml`).
2. Открой вкладку **Actions**. Сборка запускается сама после загрузки, или нажми **Build Android APK → Run workflow**.
3. Через 5–10 минут в **Releases** (справа на главной странице репозитория) появятся два APK:
   - `Jarvis.apk`: обычный, слушает, пока приложение открыто.
   - `Jarvis-Background.apk` («Джарвис Фон»): слушает «Джарвис…» в фоне через службу с иконкой в шторке и отвечает голосом при закрытом приложении. Ставится отдельно от обычного.
   Запасной путь: открой завершённый запуск в Actions и скачай `jarvis-apk-...` внизу страницы.
4. Перекинь APK на телефон и установи (разреши установку из неизвестных источников).

## Структура

- `www/`: само приложение (index.html, app.js, logic.js).
- `capacitor.config.json`, `package.json`: упаковка в приложение.
- `scripts/patch_android.py`: права на микрофон и уведомления, иконка, для фонового варианта ещё служба.
- `scripts/bg/`: Java-код фоновой службы и нативной озвучки.
- `android.yml.txt`: копия файла сборки, видимая без скрытой папки `.github`.
- `.github/workflows/android.yml`: автоматическая сборка.
